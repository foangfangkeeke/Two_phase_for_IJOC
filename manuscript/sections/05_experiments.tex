\label{sec:experiments}

This section evaluates the proposed reformulation and solution method on Tower-derived wireless charging planning instances.
The experiments use the bus network as a realistic source of shared stops, shared links, and route-level service plans, while the main purpose of the section is to validate algorithmic performance.

\subsection{Experimental design and instance families}
\label{subsec:experimental-setup}

% Paragraph plan:
% 1. Introduce the Tower-derived network as a realistic computational test bed.
% 2. Define the scenario concept once.
% 3. Define all main instance families and explain how each family maps to a later experiment.
% 4. Summarize preprocessing and parameterization.

The test instances are derived from the Tower Transit bus network in Singapore's Jurong area.
The resulting data set provides a realistic spatial structure with shared stops, shared road links, and multiple routes that may use the same wireless charging infrastructure.
We use these instances as a computational test bed rather than as a public benchmark.

Each scenario represents an alternative medium-term service plan for the same physical network, not random same-day scheduling noise.
Scenario-dependent data include the operated routes, bus duties, timetables, energy requirements, and charging opportunities induced by the corresponding service plan.
The first-stage wireless charging facilities are shared across all scenarios, whereas battery and charging-operation decisions adapt after the service plan is realized.

We use a compact instance code of the form \texttt{N-k}, where \texttt{N} indicates the network scale and $k$ indicates the number of service-plan scenarios.
Specifically, \texttt{S}, \texttt{M}, \texttt{B}, and \texttt{L} denote the small, medium, base, and large Tower-derived networks, respectively.
The capacity-coupling experiment appends \texttt{C}q to the base 10-scenario instance, where $q$ indexes the number of existing plug-in fast chargers.
The network-scale family fixes the scenario count at three and varies the physical network scale.
The scenario-count family fixes the base network and varies the number of service-plan scenarios.
Motivated by the relaxation-verification structure in Section~\ref{subsec:two-phase-framework}, the capacity-coupling family varies plug-in fast-charger capacity on \texttt{B-10} to change how strongly residual fast-charging demand couples route-level recourse decisions.
Table~\ref{tab:instance-families} summarizes the resulting instance families and their experimental roles.

Travel times are computed from link distances using a nominal operating speed of 30 km/h and then rounded to the one-minute scheduling grid.\footnote{The one-minute lower bound avoids zero-duration movements on short links and absorbs acceleration, deceleration, signal delay, and station-approach time.}
The remaining parameters specify battery costs, charging rates, charging efficiencies, electricity prices, facility costs, and state-of-charge limits.
Table~\ref{tab:parameter-settings} reports the main parameter values used in the computational experiments.

The benchmark ladder consists of five methods: the direct extensive-form MILP, baseline integer L-shaped decomposition, lifted integer L-shaped decomposition, lifted two-phase method, and the full method.
The direct extensive-form MILP optimizes the deterministic equivalent with a commercial solver.
The baseline integer L-shaped decomposition applies the classical scenario decomposition induced by the original two-stage model.
The lifted integer L-shaped decomposition uses the lifted master representation without the two-phase relaxation.
Lifted two-phase adds the Phase 1 lower-bounding and Phase 2 verification structure.
The full method further adds scenario-level monotonicity-based strengthened cuts.

This subsection uses \texttt{B-10-C1} through \texttt{B-10-C5} to test the effect of shared plug-in fast-charger capacity on the relaxation-verification structure.
Within this subsection, we denote these five variants by \texttt{C1}--\texttt{C5}; all five are built from \texttt{B-10}, and only the number of existing plug-in fast chargers is varied.
This changes how residual fast-charging demand, after accounting for wireless charging opportunities and battery choices, couples the route-level recourse problems.
The experiment is designed around the Phase 1 relaxation in Lemma~\ref{lem:phase-one-lb}, which removes shared plug-in fast-charger capacity coupling to obtain route-level LP subproblems.
When capacity is tight, the Phase 1 relaxation is expected to be less aligned with Phase 2; when capacity is loose, the two feasible regions should be closer.
The comparison is restricted to lifted two-phase and the full method because both use the same lifted reformulation, Phase 1 relaxation, and exact Phase 2 verification; the main difference is the monotonicity strengthening.
The main computational question is how the relaxation gap and Phase 2 verification burden change with capacity, and whether monotonicity strengthening remains effective as capacity coupling becomes tighter.
