# R28-N5-F50-C4 day/night tariff spread

This directory preserves the complete local run evidence for the five price levels
`s = 0, 0.5, 1, 1.5, 2`. The mean price is 0.15775 USD/kWh; the day and night
prices are `0.15775 + 0.03445s` and `0.15775 - 0.03445s`. The `s=1` Full,
no-DWC EF and fixed-plan audit records were reused from the existing
`experiments/final_2026-11-07` and `experiments/section53_2026-11-09` packages.
Eight new optimizations and four new fixed-plan audits were run serially. All
new optimizations reached the configured 1% gap; all new audits completed.

## Results

`paired_results_portable.csv` contains all five pairs, original LB/UB/gap,
certified saving intervals, DWC link counts and repository-relative raw-log
paths. The interval is `[LB_noDWC - UB_DWC, UB_noDWC - LB_DWC]`, using the
original optimization bounds. `mechanism_portable.csv` gives probability-
weighted day (DWC plus Plug-in) and night **grid-input kWh** and the
vehicle-weighted mean battery capacity for both arms at `s=0, 1, 2`.

## Reproduce

The original 24-file `data/R28_N5_data` dataset, `solverCfg.txt`, baseline
case hashes and baseline logs are already tracked on this branch. This
experiment did not remove or edit any of them. Four new input copies were
generated by changing only the day and night price fields in `globalCfg.txt`.
The exact four changed configuration files and their hashes are preserved in
`inputs/` and `plan.json`; the unchanged 23 files for each variant are obtained
from `data/R28_N5_data`.

Run on Windows with the archived COPT solver executable and license available,
using Python with `psutil`:

```powershell
C:/ProgramData/anaconda3/python.exe scripts/analysis/tariff_spread_experiment.py prepare
C:/ProgramData/anaconda3/python.exe scripts/analysis/tariff_spread_experiment.py run <new-package-path-printed-by-prepare>
```

The first command verifies the base data, `solverCfg.txt`, both archived
executables, the EF/audit source archive and the reused `s=1` evidence. It
creates the four variants under `data/` and checks that only `globalCfg.txt`
differs. The second command verifies the inputs again and runs Full using
`experiments/final_2026-11-07/versions/c29cdc5/wireless.exe` and EF/audit
using `experiments/section53_2026-11-09/versions/ef_audit/wireless.exe`.
Their exact hashes and source paths are in `plan.json`. Each launch records
the executable, arguments, input and solver configuration hashes, process
identity, wall time, resources, terminal status and original raw log. The
runner is intentionally one-shot for each prepared package; use a newly
prepared package for a fresh repetition.

`runs/` is a byte-for-byte copy of the local run evidence. `controller_source.py`
is the exact script loaded by that run. `published_manifest.json` lists the
SHA256 and size of every published file and confirms that the copied evidence
matches the original local package. The portable CSVs change only path fields
to repository-relative paths; the original generated CSVs are retained.
